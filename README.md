# IronWare
A WarioWare style game themed around Iron Man and his return to New York City through the wormhole.

<img width="692" height="391" alt="IronWare Main Menu Screenshot" src="IronWareGameScreenshot.png" />

[Try it out](https://rasmus-s.itch.io/ironware)
## Features
- 3 different minigames:
1. A platformer where you collect all 3 arc reactors before time runs out
2. A click game where you click all 6 arc reactors before time runs out
3. A timing game where you time the position of a bar inside the winning area

- A toggle for fullscreen
- Custom drawn assets
